Quick answers

What is in the export?

One row per product and info section: product_id, product_name, product_slug, section_name, section_title and section_text. Products without info sections get one row with empty section cells, so you can fill them in.

How do I change a text on every product?

Info sections are shared between products. Put the new text on every row of that section (fill down in your spreadsheet) and import: the section is updated once and every product that uses it shows the new text. The dry run says how many products that is.

How do I give one product its own text?

Change the text only on that product's row. The import makes a new section for it, named like "Shipping Info (crew-t-shirt)", and leaves the shared one alone for the other products.

How do I add or remove a section?

Add a row with the product and the section name to add it. Delete the row to remove it. A product's rows list all the sections it should have, in page order. Products that are not in the file are not touched.

Can I write plain text instead of HTML?

Yes. Plain text becomes one paragraph per line. HTML with paragraphs, bold, italic, lists and links is kept.

How do I undo an import?

Open History & undo, press Undo on the import and check the dry run. It puts the changed products back and deletes the sections the import created if nothing uses them. The undo files live in your browser; download them if you work from several computers.

My store shows a note about the earlier catalog

The app works with the new product catalog (Catalog V3). On the earlier catalog the store's own CSV export already includes the info section columns.
