This policy describes what the Church Bulletin: Weekly PDFs app ("the app") does with data.

What the app does

The app adds a widget to pages of your Wix site that shows the newest document in a folder of your site's Media Manager as this week's bulletin, lists the older ones below it, and lets visitors open or download them.

Data the app handles

  • Document details: the app's backend on Wix asks the Wix Media Manager for the public documents in the folders you picked: file name, file address, size and the date it was added. The bulletin date is read from the file name. It never reads private files, and it never copies, stores or changes any file.
  • Folder names: the settings panel lists your Media Manager folders by name, with how many documents each one holds, so you can pick one. This list is only answered for the site's owners and collaborators, not for visitors.
  • Widget settings: the folders you picked, what the folder holds (bulletin, minutes, menu or newsletter), your wording, colours, font and display options. Wix stores them with your site, like the settings of any other element.
  • Plan status: the widget and its panel ask the app's backend whether your site is on the free or the paid plan. The backend asks Wix and answers with that one fact and the app instance ID.
  • Browser storage: the visitor's browser keeps the last document list it saw (names, addresses, sizes, dates) so the list shows at once on the next visit; the dashboard page remembers whether you closed its intro box.

The backend stores nothing and keeps no logs of visitors.

Site visitors

The widget does not set cookies, does not track visitors and does not collect anything they do. When a visitor opens or downloads a document, their browser loads the file from Wix's own file servers, as it would for any file linked on your site.

Where the data goes

Nowhere outside Wix. The developer never receives your files, your folder names or anything about your visitors, and nothing is shared with anyone else.
