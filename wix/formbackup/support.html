Common questions

The page shows fewer submissions than my Forms table

The page counts the submissions the site's service returns as confirmed. A submission that is still in draft, or one that was deleted, is not in the list. Press Back up now to read the current list again.

A backup says some submissions were not covered

That is the free plan's limit: it backs up the 50 newest submissions. The message names how many older submissions were left out. Premium backs up every submission, from every form.

The weekly automatic copy did not run

Apps cannot run a timer. The automatic copy is taken the first time you open the page after seven days since the last automatic copy, so open the page once a week. Premium keeps 12 months of history.

The CSV has no file contents

Uploaded files are recorded by their file name only; the file's bytes are never copied. Download the file itself from the Forms table when you need it.

My plan looks free after I paid

Open the app again; the plan is read each time the page loads. If it still shows free, write to the address above with your site name.
