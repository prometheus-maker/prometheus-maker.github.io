Common questions

A key did not appear on the Thank You page

Check that the order is paid (not only placed), that the pool has a key for that exact product id, and that the pool is not empty. The dashboard shows the available count per product in the Keys table.

The Add button stays disabled

Paste at least one key and fill in the product id first. Duplicate keys are skipped, so a list of only duplicates adds nothing.

How do I set an expiry date?

Put a comma and a date after the key on its line, for example LK-AAAA-1111-2222,2027-06-30. Expired keys are counted apart and never handed out.

What does Premium add?

Unlimited keys in a month, CSV import and the expiry list with the keys that run out soon. Free delivers 25 keys in a calendar month.
