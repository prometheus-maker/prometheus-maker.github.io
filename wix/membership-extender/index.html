What it does

You closed the studio for two weeks, so every member's pass should run two weeks longer. That usually means opening each subscription and typing a new end date. Membership Extender does it for all of them in one go.

Pick the plans you want to change by plan, status, end date or name, then choose what to do: add a number of days, make them all end on one date (say 31 December), pause them or resume them. A preview lists every plan that will change, with the old and the new end date, and every plan that can't, with the reason. Nothing changes until you press Apply. Afterwards each plan is checked again, so the results show what really changed.

One limit comes from the plans themselves. A plan that renews every month until it's cancelled has no end date, so it can't be extended; you can pause it instead. Free plans can be extended but not paused. The preview names these plans before anything runs.

The Report tab lists members with no current plan, plans ending within the days you choose, and plans that aren't paid yet.

The free plan changes up to 10 plans per action and shows the first 25 rows of each report. Premium has no limit and downloads reports as a spreadsheet.
