What it does

An event guest list usually starts in a spreadsheet. This app takes that spreadsheet in one step, so nobody retypes names and addresses into the dashboard.

Choose an RSVP event; the app shows how many guests are already coming. Paste the rows or upload a CSV file, with commas, semicolons or tabs and quoted cells. The first row is read as column names and matched to name, email, phone, extra guests and RSVP status; any guess can be changed from a short list.

Every row is checked before anything is written. A missing name, a bad email or more than ten extra guests is marked with the reason, and rows already on the event are shown as duplicates that will be skipped, so a long list goes in with no surprises.

On import, each person becomes one RSVP, with extra guests added where the registration form offers them. A summary counts added, already there and failed rows, and downloads as a CSV file.

Free covers one event and up to 50 rows per upload. Premium removes both limits, adds phone, extra-guests and RSVP-status columns, keeps the mapping per event and can switch the duplicate check off.

The app runs inside your dashboard, with no outside server and no copy of the list.
