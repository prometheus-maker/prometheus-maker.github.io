Common questions

My event is not in the list

The app lists RSVP events only. A ticketed event sells tickets and uses reservations, which is a different flow, so it cannot take imported guests. Set the event to RSVP in your events settings to import a guest list.

My columns were matched wrongly

Change any column from the drop-down above the preview: first name, last name, full name, e-mail, phone, extra guests or RSVP status. The preview updates before anything is written.

A row is marked with a problem

A row needs a name, a properly formed e-mail address if it has one, and no more than ten extra guests. The preview says which check failed for each row.

A guest I expected is shown as already there

The app compares e-mail addresses, then first and last names, with the guests already on the event. Rows it recognises are skipped, so importing the same list twice is safe.

The plan looks free after I paid

Open the app again; the plan is read each time the dashboard page loads. If it still shows free, write to the address above with your site name.
