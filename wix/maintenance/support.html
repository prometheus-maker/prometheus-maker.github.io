Common questions

The list is empty after I install the app

Press Add 3 sample requests to try the list with example rows, then delete them and add your own with Add request. A fresh site starts with no requests.

I cannot add a second property on the free plan

The free plan covers one property and ten requests. The list header says so, and the upgrade card above it opens the plan page. Premium removes both limits.

The contractor and due date fields are greyed out

Contractor assignment and due dates are part of Premium. The form says so under the fields.

The plan still looks free after I paid

Open the app again; the plan is read each time the dashboard page loads. If it still shows free, write to the address above with your site name.
