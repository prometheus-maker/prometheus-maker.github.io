Common questions

The panel says my 100 older reviews are not covered

The free plan backs up the 20 newest reviews. Premium backs up every review and every moderation status.

A review is missing after a backup

A review deleted or hidden on the site stays in the backup it was saved in. The next backup lists it under "Missing since the previous backup". Premium can restore it from the newest backup, as a new review pending moderation.

Restore created a duplicate?

It should not: restore compares the newest backup with the live site by review id and records every id it restores. If you see a duplicate, write to us with the review id and the time of the restore.

Where do the CSV files go?

The CSV button on a backup downloads one file with one row per review. Nothing is sent by e-mail.
