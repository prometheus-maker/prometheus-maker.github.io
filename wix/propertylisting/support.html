Common questions

No properties appear on my site

Only properties marked as listed appear. Open the app in the dashboard, check the Listed switch on each property and save it. On the free plan the site shows the first three listed properties; Premium shows all of them.

The card shows a coloured tile instead of a photo

A property uses its photo when the Photo URL field holds a direct link to an image. When it is empty, the card shows a tile with the property type instead. Paste a direct image link to show the photo.

The date filter hides a property I expect to see

The filter checks the availability window you set on each property. A stay must fit inside that window. A property with an empty window counts as available all year.

The Enquire button does nothing

Enquire opens the visitor's own mail app with a message addressed to the property's enquiry e-mail. If no mail app is configured on the visitor's device, the button cannot open one. Check that the enquiry e-mail is filled in for that property.

The plan looks free after I paid

Open the app again; the plan is read each time the dashboard page loads. If it still shows free, write to the address above with your site name.
