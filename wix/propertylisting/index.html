What it does

Renting out more than one property means the details live in a spare document and a chat thread. This app puts them in one place and shows them on your site as a directory visitors can search.

Each property is a row in the dashboard: title, type, location, guests, bedrooms, nightly price and the window when it is available, with a description, photo link and enquiry address. Every property marked as listed appears as a card on the site.

The free plan lists three properties with a photo or type tile, name, location, guests, bedrooms and price, and an Enquire button that opens the visitor's mail app addressed to the owner.

Premium lifts the limit and adds a filter bar. Visitors choose arrival and departure dates, guests, a maximum nightly price and a property type, and only the homes free for those dates and matching the party remain. The date filter checks the availability window set on each property, so a house closed for the winter does not appear for a December stay.

The list exports as CSV, properties can be hidden without deleting them, and an empty site can be filled with a sample set first.

Premium is $6 a month, or $5 a month billed yearly.
