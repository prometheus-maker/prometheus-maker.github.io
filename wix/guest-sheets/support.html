Quick answers

Which guests are in the sheet?

One row per ticket and one per RSVP guest who said yes. Tickets from canceled or declined orders are left out. Buyers are not separate rows.

Why does one person's name appear on several rows?

If tickets were not assigned to separate guests, every ticket in the order gets the buyer's name and answers.

Where are my registration questions?

Each question on an event's registration form becomes a column, marked with ✎ in the column list. Questions with the same name in several events share one column.

Which file type should I pick?

CSV (comma) opens in most programs. If Excel puts everything in one column, pick "CSV for Excel in Europe (semicolon)". To paste into Google Sheets, pick tab-separated.

Why does a cell start with an apostrophe?

Values that start with =, +, - or @ could run as a formula in a spreadsheet, so the app adds an apostrophe to keep them as plain text.

What does the summary count?

Tickets sold, gross, discounts and net per event and ticket type, from orders that are not canceled or unfinished, with totals per category and for all events.
