Support: PDF Viewer: Document Library

Support is open to everyone, on the free and the paid plan.

How to get help

  • Email: prometheus.maker@proton.me. Include your site address, the page with the list and what you saw. A screenshot helps.
  • Replies usually go out within two business days.

Quick answers

Where is the list?

Installing the app adds the list to the page you were on, in its own section. To add another, open the editor, click Add Elements, then App Widgets (or My Widgets), then Document Library.

Which folder does it show?

The first time you open Settings, it picks the Media Manager folder with the most documents. Click the list in the editor, then Settings, and choose another folder from the list if you like. Each folder shows how many documents it holds.

I added a PDF to the folder. Do I need to publish again?

No. The list is read when a visitor loads the page, so a new file shows the next time the page is opened.

A file in the folder does not show

Only public documents are listed (PDF, Word, Excel, PowerPoint, text). Private files, images and videos are left out.

Why does a PDF open in a new tab on my phone?

Most phones can't show a PDF inside a page. The phone's own viewer reads it better, with zoom and sharing.

Can visitors search the documents?

Yes, on Premium: turn on "Search the documents" in Settings.

What happens if I cancel Premium?

The list keeps working with one folder. Tabs, search, cards, sort order, the "New" label and hiding the download button switch off, and the small credit link comes back.

Privacy

See the privacy policy. In short: the app lists the public files you picked and never reads private files.
