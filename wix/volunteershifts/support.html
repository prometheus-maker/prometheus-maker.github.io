Common questions

Nothing appears on my site for volunteers

The sign-up widget is a Premium feature. Add it to a page from the editor: Add Elements, Apps, Volunteer Shifts. Until then the board in the dashboard still works.

A volunteer did not get the confirmation or the reminder

The message goes to the address typed at sign-up. A typo cannot be corrected from the board; add the person by hand in the dashboard instead. Reminders go out two days before the shift, and only for people marked going.

A shift is full but someone still signed up

Two people can take the last place at the same moment; the board shows the over-booked place rather than hiding it. Remove the extra person from the person view.

The cancel link says the link is not active

The link works once. If the place is already cancelled, there is nothing more to do. If the message says the link was cut in two, open it again from the email without copying it.

The plan looks free after I paid

Open the app again; the plan is read each time the dashboard page loads. If it still shows free, write to the address above with your site name.
