Common questions

My backup does not include every file

The Free plan backs up the newest 100 files. The page shows how many files you have and how many are left out; Premium covers every file in every folder.

The ZIP does not contain my images

The ZIP carries a manifest with one row and one link for every file, not the file contents themselves. File contents stay in your media library and are never copied or sent anywhere by the app. A ZIP of a very large library works the same way, because there is no size cap.

Where does the automatic copy go

Premium takes a weekly automatic copy the first time the app's dashboard page is opened after seven days. Apps cannot run a timer, so a week in which the page is never opened has no automatic copy; press Back up now for one at any time.

A file shows as missing

A file is reported as missing when it was in the previous backup and is not in the new one, for example after it was deleted from the media library. The backup keeps its name and link so you can see what it was.

The plan looks free after I paid

Open the app again; the plan is read each time the dashboard page loads. If it still shows free, write to the address above with your site name.
