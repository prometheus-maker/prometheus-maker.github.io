What it does

Every image and every file a site uploads lives in one media library: product photos, documents, old banners. The library grows all the time, with no single view and no export of the whole thing.

This app reads your media library and counts it: how many files, folders and how much space they take. One press saves a dated backup of the inventory: every file's name, folder, size, upload date and its link, kept in the app's own storage.

Each backup downloads as a CSV that opens in any spreadsheet. The next backup compares itself with the last and lists new, missing and changed files by name, so a file that disappeared is noticed while you still know what it was.

The Free plan backs up the newest 100 files and keeps two backups. Premium backs up every file in every folder, keeps twelve months of history, adds a ZIP download and takes an automatic copy the first time you open the app after seven days.

The ZIP carries a manifest and a link for every file rather than the file bytes, so there is no size cap however large the library is. File contents stay on the site and are never copied or sent anywhere. Premium is $5 a month, or $4 a month billed yearly, with a 14-day free trial.
