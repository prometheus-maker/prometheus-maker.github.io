Common questions

The page says it could not read my bookings

The app reads bookings with your signed-in session. Reload the dashboard page and try again. If the message stays, write to the address above with your site name and the time you tried.

How much does the free plan back up

The free plan covers the last 30 days of bookings and the next 10 upcoming sessions, and keeps the two most recent copies. The page shows how many bookings your site has and how many are outside that window before you take a copy.

What is in the ZIP

A bookings file with one row per booking (service, times, staff, status, payment status, client contacts) and, on Premium, a clients file with one row per client. Both are plain CSV that opens in any spreadsheet.

The automatic copy did not run

Apps cannot run a timer. The automatic copy is taken the first time you open the page after seven days, on Premium, and the page shows the time of the last copy.

The plan looks free after I paid

Open the app again; the plan is read each time the dashboard page loads. If it still shows free, write to the address above with your site name.
