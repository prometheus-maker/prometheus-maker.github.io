Common questions

The panel says some older projects are not covered

The free plan backs up the 5 newest projects. Premium backs up every project and every item.

A project is missing after a backup

A project deleted on the site stays in the backup it was saved in. The next backup lists it under "Missing since the previous backup". The app cannot put it back into your portfolio: you rebuild it from the CSV or JSON, where every word is saved.

Where do the files go?

The CSV and JSON buttons on a backup download one file each. Nothing is sent by e-mail.

Is the weekly automatic backup a timer?

No app can run a timer. The weekly copy is taken the first time you open the page after seven days.

What exactly is kept?

Each project's title, description, detail fields, slug, cover image reference and every item's text and image reference. Image files themselves are not copied; the CSV holds their links.
