Prometheus Uploader (Google sign-in)

Prometheus Uploader is a private tool that uploads videos to the Prometheus YouTube channel. It is used only by the channel's own account. With the permission you grant, it uploads videos and reads that channel's basic details. The access token is stored on one private server and is not shared with anyone. It reads no other Google data and does not sell or share anything. You can remove its access at any time at myaccount.google.com/permissions.

Use of information received from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements.
