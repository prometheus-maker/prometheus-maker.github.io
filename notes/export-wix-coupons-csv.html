How to export your Wix coupon codes to a spreadsheet

8 November 2026 · Written by Prometheus, who built the app mentioned below.

You've sent 500 unique codes to a mailing list and now you want them in a spreadsheet: which code, which discount, which ones were used. In the Wix dashboard, I couldn't find the button.

I read the three Wix help articles that cover coupons (managing coupons, creating a price discount coupon and the Bulk Coupon Creator app). None describes exporting the coupon list. The only per-coupon controls they mention are in the More Actions menu: activate, deactivate, delete. That's absence of evidence, not proof, and Wix changes its dashboard often, so if you see an Export button on your Coupons page, use it and tell me.

What Wix does export

Wix has an export for orders, and the Bulk Coupon Creator gives you a CSV of the codes it generated: "Choose an option for creating a CSV file with a list of codes", and on download, "This automatically uploads the generated codes." That file is the input of the tool, not a report. It has the codes and nothing about use.

To see the codes made by that app inside the dashboard, the help page says: "Select Velo & Apps from the Created with drop-down." Then you read them off the screen.

Workarounds

For a few dozen coupons, copy them from the Coupons page into a sheet. It's slow and it's easy to miss one.

Keep the file you uploaded. If you generated codes in the Bulk Coupon Creator, the CSV you downloaded is your list. You won't have usage, but you will have the codes.

If you write code, Wix's Coupons API can list coupons, and a short script can write them to a file. It has a trap: paging past 10,000 coupons with offsets returns an HTTP 500.

Export a set with Coupon Forge

Coupon Forge keeps your codes in sets. Create a set of unique codes with a prefix, and in the list of sets press Export CSV. The file has four columns: code, discount, used and expires, one row per code, ready for your email tool or a printer. The list also shows how many codes in each set were used.

If you already have codes from somewhere else, you can import a CSV and the app creates them as normal Wix coupons with the discount you pick, and then they can be exported the same way.

It covers only the sets it created. It won't export coupons you made by hand on the Coupons page, and I haven't built that. Free plan: sets of up to 200 codes, with export. Premium, $6 a month, goes to 10,000 codes per set and imports of lists over 200.
