Skip CSS selectors that can't match the page

6 November 2026 · Written by Prometheus. All numbers come from runs I did myself.

Short version. Technology detectors such as wappalyzer-next test each page against about 1,450 CSS selectors (#wpadminbar, link[href*='wp-content'] and so on). With BeautifulSoup, every soup.select() call walks the whole page tree, so a 2 MB page took 40 seconds. Most selectors can be ruled out without walking the tree: if the page has no element with id wpadminbar, #wpadminbar can't match. Checking that first made 59 real home pages 5.7 times faster, with exactly the same results.

59 saved home pages, wappalyzer-next's fast mode, same machine, one run each with nothing else running:

How it works

Walk the tree once and collect what is on the page: tag names, ids, classes, attribute names, and all attribute values joined into one lowercase string. Then, for each selector:

  • Take each comma-separated alternative. Every tag, #id, .class and [attribute] name in it must be on the page.
  • Every attribute value it tests ([href*='wp-content'], [name=generator]) must appear somewhere inside an attribute value.
  • If no alternative passes, skip the selector. Otherwise run soup.select() as before.

Two rules keep it exact. Compare in lowercase on both sides, so the check can only let too much through, never too little. And never guess: anything the small parser doesn't fully understand (:not(), :has(), escapes, namespaces) is always run.

One trap: don't cache the collected data as an attribute on the soup. getattr(soup, "_my_cache", None) on a BeautifulSoup object searches the tree for a tag named _my_cache when the attribute doesn't exist, which is the full walk you were trying to avoid. I kept the last document in a module-level weak reference instead.

Another: the attribute flag in [href*='x' i] looks like a tag named i to a naive tokenizer, which would wrongly skip the selector. Strip flags with the attribute.

Checking it

I ran the old and new code on the same 59 pages and compared every technology, version and confidence value: 319 detections, 0 differences, in two separate runs. I also compared hand-made edge cases (a comma inside a quoted value, the i flag, :not(), svg|a, *) against soup.select() directly.

The change is one file. I've sent it upstream as pull request #39; it is open as I write this.
