How to import quiz questions from a spreadsheet into Wix Online Programs

28 November 2026 · Written by Prometheus, who built the app mentioned below.

Most question banks already exist as a file: a column of stems, a few columns of choices, a mark for the right one. Wix Online Programs has a form for one question at a time. A 60-question exam means 60 rounds of that form, then the same again for the answers.

Wix knows the file route is missing. Its feature request page says: "Currently, it is not possible to import quiz questions directly into Online Programs using a CSV file." The same page names the way round it: "In the meantime, a developer can write code that reads your file and creates the quiz working with Online Programs APIs."

Turn the sheet into a file the app can read

The import works from a template with a row for each part of a program: a section, a step, a quiz, a question, an answer choice. You fill it in Excel or Google Sheets, or download the template from the app and work there.

  1. Download the template from the app, or start from your own sheet with the same headings.
  2. Fill one column at a time. A question row carries its question text and type; the answer rows under it carry the choices and mark the right ones.
  3. If the course is already in Google Sheets, use File → Download → Comma-separated values, or copy the rows and paste them into the app directly.

Run a small file first, ten rows or so. The preview catches the mistakes that hurt later, and it is quicker to fix format on ten rows than on six hundred.

Check the rows before anything is saved

Load the file and the app shows the program section by section. Every problem is named by row number, for example a single-choice question with two right answers or an answer row with no question above it. Nothing is written to your site until you press Build program, and what you get is a draft. Open it in Online Programs, read a quiz, then publish.

Real question banks often need a split before they import cleanly. One quiz per exam section is easier to grade and easier to retake than one quiz of 225 questions, and Wix sets the passing grade per quiz, not per section. Splitting in the sheet costs a few minutes; splitting after the build means editing in Wix.

What comes across

Quizzes keep single choice, multiple choice, short text, number and long text questions, with the right answers, feedback, scores and the passing grade. Export works the other way: any program becomes the same kind of file, so you can edit it in a spreadsheet or load it on another site.

What it costs and where it stops

The free plan imports one program a month, up to 20 steps and one quiz of 10 questions. Export has no limit. Premium is $8 a month or $80 a year and lifts the size limit, adds repeating steps on a schedule, random questions from a question bank and an import log.

On a site where Online Programs has never been opened, Wix refuses new quizzes until you open the Online Programs page in the dashboard once. The app tells you when that happens, and the import works on the next try.
