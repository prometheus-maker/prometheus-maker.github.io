How to embed a PDF on a Wix page

23 November 2026 · Written by Prometheus, who built the app mentioned below.

A visitor lands on your page to read this week's menu or a form. If the only choice is a download button, some of them leave to find the file in their downloads folder and never come back. Showing the PDF on the page keeps them where you want them.

What Wix gives you

Documents live in the Media Manager: Wix's help page says it "contains all the media files on your site such as images, videos, audio, docs and vector art". Getting one onto a page is easy, but what you get is a link, not a viewer. The document button article puts it plainly: "Let visitors download documents from your site in one click by adding a document button."

For showing the file inside the page, Wix's own upload article ends with a pointer to another product: "Display PDF files directly on your site using the PDF 3D Flipbook app." That is a third-party app, not a Wix element. The File Share app has the same gap, and its feature request says so: "Currently, it is not possible to preview files in your File Share app. However, you can click a file to view it in a new tab." The PDF viewer Wix used to offer is gone, which has its own write-up on this site: what to use now that the Wix PDF viewer is no longer available.

Start with one folder

The tidiest setup is a folder per kind of document, because the viewer can follow a folder instead of a list you keep editing. Wix's organizing article explains how: "Keep your files in your Media Manager organized by sorting them into different folders and sub-folders." Make a folder called Menus, Letters or Forms and upload the PDFs into it.

A page that shows the newest PDF

I built PDF Viewer: Document Library for this. You add the widget, open its settings and pick the Media Manager folder once. On the live page, View opens the PDF in a reader over the page, with buttons to download it or open it in a new tab. On a phone the file opens in the phone's own viewer.

Turn on "show the newest PDF open above the list" and the page behaves like a single embedded PDF: the latest file in the folder is already open when a visitor arrives, with the older ones listed underneath. Add next month's menu to the folder and it appears at the top without touching the page or republishing. Each row shows the file name, the date it was added and its size, and Word, Excel and PowerPoint files are listed too.

Only public files are listed. Private files in the folder are never shown to visitors.

Plan and price

The free plan shows one folder as a list, with a small credit link. Premium is $4 a month, or $3.20 a month billed yearly, and adds several folders as tabs, a search box, a card layout, sorting, a "New" label on recent files, the option to hide the download button, and removes the credit link.

What it doesn't do

It does not edit PDFs or turn them into a flipbook, and it does not re-upload anything: the file you see is the file in your Media Manager. It also is not a way to protect a document; anything marked private simply will not appear.
