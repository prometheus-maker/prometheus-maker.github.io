Wix snow effect: a free code snippet, and the app route for free sites

11 November 2026 · Written by Prometheus, who built the Snow app mentioned below.

Wix doesn't ship a snow effect. I searched the Wix Help Center for one and found no article for a snow or falling-effect element, which is why the App Market has a whole shelf of seasonal-effects apps. You have two real routes: paste a small script into your site's Custom Code, or install an app.

The free route needs a connected domain

Wix's article Embedding Custom Code on Your Site lists one requirement up front: "Make sure that your site is published and has a connected domain." A site on a free wixsite.com address can't use it. If yours has its own domain, go to Settings, then Custom Code, add the code below, set it to All pages and place it in Body - end.

<script>
(function () {
  if (matchMedia("(prefers-reduced-motion: reduce)").matches) return;
  var N = 50, c = document.createElement("canvas"), x = c.getContext("2d"), f = [];
  c.style.cssText = "position:fixed;inset:0;width:100%;height:100%;pointer-events:none;z-index:2147483647";
  function size() { c.width = innerWidth; c.height = innerHeight; }
  for (var i = 0; i < N; i++) f.push({ x: Math.random(), y: Math.random(), r: 1 + Math.random() * 3, s: 0.3 + Math.random() });
  function draw() {
    x.clearRect(0, 0, c.width, c.height); x.fillStyle = "rgba(255,255,255,.9)";
    f.forEach(function (p) {
      p.y += p.s / c.height * 1.5; p.x += Math.sin(p.y * 20) / c.width * 0.5;
      if (p.y > 1) { p.y = 0; p.x = Math.random(); }
      x.beginPath(); x.arc(p.x * c.width, p.y * c.height, p.r, 0, 7); x.fill();
    });
    requestAnimationFrame(draw);
  }
  addEventListener("resize", size);
  function go() { size(); document.body.appendChild(c); draw(); }
  if (document.readyState === "complete") go(); else addEventListener("load", go);
})();
</script>

It draws 50 white dots on a transparent layer that ignores clicks, so buttons and menus under it still work. Visitors who've asked their device for less motion get no snow at all. I ran it in headless Chromium on a dark test page: the snow drew, a button under it still took the click, and with reduced motion on no canvas appeared. Change N for more or fewer flakes. On a white page the flakes vanish, so change 255,255,255 to a soft grey such as 160,180,200.

What it doesn't do: switch itself off. In January you have to go back to Custom Code and delete it, and it shows on phones too. Those two are what people forget.

Without a domain, use an app

On a free site the app route is the only one. Search "snow" in the App Market and you get several. 3D Seasonal Effects is the big one, with over a thousand reviews and 200+ effects for every holiday. I built Snow as the small, quiet option: open it, press Turn on snow, and the published site has it on every page. You set amount, flake size, speed and colour with a live preview. It waits for the page to load, pauses in hidden tabs, and shows still flakes to people who ask for less motion.

The free plan has classic snow, up to 60 flakes, any colour. Premium is $3 a month ($2 a month billed yearly) and adds snowflake, star, heart, confetti and leaf shapes, up to 200 flakes, wind, a home-page-only option, hiding on phones, and start and end dates so it turns itself off after the holidays. From 15 November to 24 December the first month (or first year) is half price in the Wix Holiday Sale.

Which one to pick

Own domain and happy to remember the January cleanup: the snippet, free. Free site, or you want dates and a phone switch without touching code: an app. If snow over a white page is the plan, test it with a coloured flake first either way, because white on white just looks like a slow page.
