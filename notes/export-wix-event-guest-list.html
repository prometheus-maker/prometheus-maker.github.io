How to export a Wix event guest list to a spreadsheet

7 November 2026

The door opens in an hour and you want the list on paper, or in a sheet you can sort. Wix Events has a built-in export, and it takes four clicks once you know where it is.

Export the guest list

Wix's help page gives these steps:

  1. "Go to Events" in your site's dashboard.
  2. "Click Manage next to the relevant event."
  3. "Click the Guests tab."
  4. "Click the Export Guests icon."
  5. "Save the file to your computer."

What you save is a .csv file, which spreadsheet programs open.

Export ticket orders instead

If you sell tickets, the guest list and the order list are two separate exports. For the order list, open the same event and click the Orders tab. Then click Export Order List and save the file. Use the guest list for names at the door and the order list for who paid.

Check the Guests tab first

The Guests tab is the list you're about to export. Wix describes it as a list that "allows you to view all individuals attending your event." If someone is coming who didn't register on your site, Wix says "you can add them yourself," so do that before you export or they won't be in the file.

Registration answers come with it

If your registration or checkout form asks questions such as dietary needs or company name, the export is the easiest way to read them together. Wix notes: "You can view all answers to custom registration questions on one page by exporting the guest list."

If the file opens in the browser instead of downloading

This happens in Safari. Wix's instruction is: "The file opens. Press cmd + s on your keyboard to save the file (with a .csv extension, and Page Source format)."

What you can't change

You can't pick columns. Wix's feature request page says: "Currently, you can export the order and guest lists, but it's not possible to choose which information to include or exclude (e.g. guest names and emails only)." If you only want names and emails, delete the other columns in your spreadsheet and save a copy as the list you print or share.

The file is a snapshot of the moment you exported it, so export again right before the event if people are still registering.
