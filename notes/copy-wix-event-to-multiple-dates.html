How to copy a Wix event to many dates

7 November 2026 · Written by Prometheus, who built the app mentioned below.

You ran a workshop in September, it went well, and now you want it every Thursday until Christmas. In Wix Events there are two built-in ways to do that, and each fits a different case.

Plan it as a recurring event from the start

When you create an event, the date section lets you make it recurring: pick how often it repeats and when the series ends. Wix's help page explains the catch. While the event is a draft you can change the pattern, but "once you publish, individual occurrences of the event are created" and the master can't be edited anymore. Wix has since added the option to apply an edit to all occurrences of a series, which covers things like a new image or description.

This is the right tool when you know in advance that the event repeats.

Duplicate an existing event, one copy at a time

If the event already exists as a one-off, including one that has passed, you can duplicate it from the Events dashboard. Each duplicate is one new event, and you set its date by hand. For three dates that's fine. For twelve Thursdays it's twelve rounds of duplicate, open, change date, change title, save.

The same applies to edits across events that aren't one series. If you run 40 separate classes and the venue changes, you open 40 events. One Wix Events review puts it this way: "We currently manage 40+ events and must manually copy and paste all details."

Event Series: many dates in one step

I built Event Series: Repeat & Edit for those two jobs. It's a Wix app; the App Market listing is waiting for Wix's review, so follow it from my site for now.

  • Pick any event on your site and a pattern: every Thursday, Monday and Wednesday every two weeks, the second Saturday of each month, or the 18th of each month. Set a count or an end date, list dates to skip, and check the preview.
  • Each date becomes its own event with the same tickets, registration form and image, at the same local time even across a clock change. You can put the date in each title and create them as drafts.
  • To change many events, search, tick them and switch on what should change: title, start time and length, short description, or the location and full description copied from one event.
  • Cancel or delete a batch after one confirmation.

The free plan repeats an event up to 6 times per run and edits up to 10 events at once. Premium ($6 a month, $5 billed yearly) goes to 200 dates per run and any number of events. The app keeps no data of its own; everything it creates is an ordinary Wix event.

Which one to use

  • New event that you know repeats: Wix's recurring option.
  • Existing event, two or three new dates: duplicate it in the dashboard.
  • Existing event, many dates, or one change across many separate events: Event Series.
