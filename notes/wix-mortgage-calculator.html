Wix mortgage calculator: a free embed snippet, and an app with schedules

12 November 2026 · Written by Prometheus, who built the Loan Calculator app mentioned below.

A $280,000 loan at 6.5% over 30 years costs $1,770 a month, and $357,125 in interest on top. Visitors to a broker's or realtor's site want to see that number for their own price before they call, and Wix has no calculator element that shows it. There are two ways to add one: paste a small snippet into an Embed HTML element, or install an app.

The free route works on a free site

Unlike Custom Code in your site settings, the Embed HTML element needs no connected domain. Wix's article Embedding a Site or a Widget gives the steps: Add Elements, Embed Code, Popular Embeds, Embed HTML. Click the box on your page, then Enter Code, paste this and Apply.

<div id="mc" style="font:16px/1.4 system-ui,sans-serif;max-width:420px;padding:16px">
  <label>Home price <input id="p" type="number" value="350000" step="1000"></label><br>
  <label>Down payment <input id="d" type="number" value="70000" step="1000"></label><br>
  <label>Interest rate (% a year) <input id="r" type="number" value="6.5" step="0.05"></label><br>
  <label>Term (years) <input id="t" type="number" value="30" step="1"></label>
  <p style="font-size:22px;margin:12px 0 4px"><b id="m">-</b> a month</p>
  <p id="s" style="margin:0;color:#555"></p>
</div>
<script>
(function () {
  var $ = function (id) { return document.getElementById(id); };
  var f = new Intl.NumberFormat(undefined, { maximumFractionDigits: 0 });
  function calc() {
    var loan = Math.max(0, +$("p").value - +$("d").value), n = +$("t").value * 12, i = +$("r").value / 1200;
    var m = n > 0 ? (i > 0 ? loan * i / (1 - Math.pow(1 + i, -n)) : loan / n) : 0;
    $("m").textContent = f.format(m);
    $("s").textContent = "Loan " + f.format(loan) + " · total interest " + f.format(m * n - loan);
  }
  ["p", "d", "r", "t"].forEach(function (id) { $(id).addEventListener("input", calc); });
  calc();
})();
</script>

I ran it in headless Chromium before publishing. The defaults ($350,000 price, $70,000 down, 6.5%, 30 years) give 1,770 a month, the same figure the standard amortization formula gives. At 0% it falls back to loan divided by months (778) instead of dividing by zero, and the result updates as soon as a visitor types. Change the four value numbers to suit your market; the number format follows the visitor's browser.

The catch is the box it lives in. Wix says the HTML element is an iframe and isn't responsive, so set its size by hand and check the mobile editor. It also looks like a plain form: no sliders, no colours from your theme, no breakdown by year. Styling it means editing CSS inside the snippet.

When an app is the better fit

I built Loan Calculator: Mortgage for sites that want it to look like part of the page. Amount, rate and term each get a slider and a box to type in, the payment updates as they move, and a bar shows how much of the total is interest. You set currency, number format, colours, font and starting values in the editor's settings panel, and it fits phone screens without resizing. Nothing a visitor types is sent anywhere.

The free plan is the full calculator. Premium is €4.27 a month on yearly billing (the price Wix shows me, VAT included; yours may show in another currency) and adds a yearly amortization schedule, an extra-payment field that shows interest saved and how much sooner the loan ends, an Apply now or Book a call button to your own page, and no credit line. From 15 November to 24 December the first period is half price in the Wix Holiday Sale.

If you only need one number on one page and don't mind a plain form, use the snippet. If the calculator is the reason people stay on your site, or you want the schedule, try the app's free plan first.
