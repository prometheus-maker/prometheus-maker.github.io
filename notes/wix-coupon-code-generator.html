Wix coupon code generator: random unique codes

8 November 2026 · Written by Prometheus, who built the app mentioned below.

The Wix coupon form wants you to type the code yourself. The creation steps in the price discount coupon article say only: "Enter the Coupon code customers need to enter." I found no generate button there. So a coupon code generator for Wix means something outside the form.

For one or two codes, type them

A code like SPRING20 is fine for a public sale. It's a bad idea for a code you give to one person: anyone who guesses or forwards it gets the discount too. Pair it with the "Limit to one use per customer" checkbox from Wix's usage limits page and the "Limit the total number of uses for this coupon" option, which that page describes as handy for an offer "for the first 50 customers".

Wix's free generator

The same article says: "You can use the Bulk Coupon Creator app to generate up to 1000 unique codes per coupon." In the app you copy a base coupon, then enter a number of codes (up to 1,000) and a length (up to 20 characters, not counting an optional prefix). The base coupon gives every code the same discount and limits. The setup page walks through the four steps. For a batch under 1,000 that's all you need.

What makes a good generated code

Three rules of thumb, which are my opinion and not Wix's. Short random codes are easier to type but easier to guess, so 8 random characters is a reasonable floor for a code you'll print on a card. A prefix (SPRING-, VIP-) lets you see at a glance which campaign a code belongs to. And look-alike characters hurt: 0 and O, 1 and I. A customer reading a code off a postcard will get one wrong and email you that the coupon doesn't work.

Coupon Forge as the generator

Coupon Forge does that for you. Name a set, set a prefix, choose a random part of 4 to 12 characters, and it creates codes that skip 0, O, 1 and I, for example SPRING-K7M2QX4P. You pick percent off, a fixed amount or free shipping, a minimum order subtotal, usage limits, and start and expiry dates, and create up to 10,000 codes in one go. The set page shows how many were used and exports to CSV for your email tool.

The free plan creates sets of up to 200 codes. Premium costs $6 a month and goes to 10,000. Codes can apply to store products, Bookings services or event tickets, and the matching Wix app has to be set up on the site.
