Field Usage Map for Jira

Every Jira field, the screens and schemes that use it, and the projects behind them.

Build a tree per field - screens and tabs, screen schemes, projects - with filters for unused fields and a CSV export.

What it does

As a Jira site ages, fields accumulate: created for a project that no longer exists, kept for a migration that finished, still on a screen nobody uses. Jira's admin pages show fields from the screen's point of view, one scheme at a time, and never in one place.

Field Usage Map builds the missing view. It walks the site's fields, screens, screen schemes and projects and shows a tree for each field: which screens and tabs carry it, which screen schemes include those screens, and which projects use those schemes, with a badge counting the projects. Filters narrow it to all fields, fields on no screen, or fields in no project - the candidates for deletion.

The build runs in steps (fields, screens forty at a time, schemes, project lists twenty at a time) and keeps the map in storage so it can be reloaded without rebuilding. A CSV export of the current view is available for a clean-up meeting. Nothing is written to Jira; every endpoint used is a read.

Install

Where to install it: Jira Cloud, from the Atlassian Marketplace.

Open Apps → Manage your apps in Jira, choose Find new apps, search for the app name and click Install.

What you can do with it

You find it under Jira settings → Apps → Field Usage Map for Jira.

  • A tree per field: screens and tabs, screen schemes, projects
  • A project count badge on every field
  • Filters for all fields, on no screen, and in no project
  • Incremental build that finishes in steps and can be reloaded
  • CSV export of the current view
  • Read-only; stored map removed on uninstall

Your data

The app runs on Atlassian Forge inside your own site. Settings and any cached results are stored in Forge storage, which belongs to your site; nothing is copied to another service, and nothing is read beyond what the app needs to do its job. Removing the app removes what it stored. Details: privacy policy.
