JQL Snippet Library

Keep the team's JQL queries named, described and in one place.

Save JQL snippets with a description and tags on a project page, test them against Jira, and share them with the project or keep them private.

What it does

Every project has a handful of JQL queries people retype or paste from a chat thread: the release filter, the stale-ticket check, the one that finds issues missing an estimate. They live in bookmarks and memory, and only the person who wrote them can fix them when they break.

JQL Snippet Library is a project page that stores those queries with a name, a description and up to 20 tags. A snippet is private to its author until it is marked shared, at which point everyone on the project sees it. Name, description, JQL and tag searches narrow the list, and duplicate names within a scope are rejected so two "My open bugs" cannot drift apart.

Each snippet can be tested before it is saved: the app asks Jira for an approximate count and shows the number, or the error Jira returns, so a query is fixed at the point it is written. Opening a snippet counts a use and records the last count, which makes the queries nobody opens visible. Open in Jira sends the snippet to the issue navigator as a normal JQL search.

Snippets are stored by the app for the project, not as Jira filters - nothing is created in Jira. JQL is capped at 2000 characters, and authors edit their own snippets while project admins can edit or delete any snippet in the project. All stored snippets are removed on uninstall.

Install

Where to install it: Jira Cloud, from the Atlassian Marketplace.

Open Apps → Manage your apps in Jira, choose Find new apps, search for the app name and click Install.

What you can do with it

  • Named JQL snippets with a description and up to 20 tags
  • Private by default, shared with the whole project when you tick Shared
  • Search across name, description, JQL and tag
  • Test a query against Jira before saving, with the count or the error
  • Use count and last count per snippet, so unused queries show
  • Open in Jira hands the query to the issue navigator
  • Project admin override; all snippets removed on uninstall

Your data

The app runs on Atlassian Forge inside your own site. Settings and any cached results are stored in Forge storage, which belongs to your site; nothing is copied to another service, and nothing is read beyond what the app needs to do its job. Removing the app removes what it stored. Details: privacy policy.
