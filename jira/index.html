Jira and Confluence apps

Small, focused apps for Jira Cloud and Confluence Cloud. Each one does a single job and keeps its data inside your site.

  • Comment Templates for Jira
    Insert a saved comment into a Jira issue in one click, with the issue's details filled in.
  • Label Manager for Jira
    Count, rename, merge and delete Jira labels in bulk, with a dry run first.
  • Bulk Clone for Jira
    Clone many Jira issues at once, with their subtasks, links and attachments.
  • Field Auditor for Jira
    Find unused and empty custom fields, screens and schemes.
  • Last Comment for Jira
    See, sort and filter issues by their latest comment.
  • Incoming Links for Confluence
    See which pages link to this one, grouped by space.
  • Watcher Manager for Jira
    Add or remove watchers on many issues at once, with a preview first.
  • Time in Status for Jira
    See how long issues spend in each workflow status.
  • Attachment Cleanup for Jira
    Find oversized and unattached Jira attachments, then delete them safely.
  • Checklist Progress for Jira
    A checklist field whose progress percentage is searchable in JQL.
  • Template Gallery for Jira
    Project templates that create a full set of issues and sub-tasks in one click.
  • Component Bulk Ops for Jira
    Rename, merge, delete or reassign leads on project components across every issue at once.
  • Version Bulk Ops for Jira
    Release, archive, merge or delete project versions across all their issues at once.
  • Required on Transition for Jira
    Block a workflow transition until the fields your team needs are filled in.
  • Copy Field on Transition for Jira
    Copy one field's value into another whenever an issue moves through a transition.
  • Unresolved Comments for Confluence
    Every open inline comment on your Confluence site, on one page.
  • Bulk Due Date Shift for Jira
    Move many due dates by the same number of days, safely and in the background.
  • Issue Link Matrix for Jira
    See how issues in a set are linked to each other, type by type.
  • Sprint Carryover Report for Jira
    See per assignee how much work carries from sprint to sprint.
  • Field Permission Guard for Jira
    Keep sensitive field values out of the wrong hands, and put back any that are changed.
  • Duplicate Issue Detector for Jira
    Point a new issue at the one it probably duplicates, before anyone works twice.
  • Watcher Digest for Jira
    Everything that changed on the issues you watch, in one page.
  • Issue Age Heatmap for Jira
    How old your open work actually is, as a dashboard heatmap.
  • CSV Field Bulk Set for Jira
    Paste a CSV of issue keys and field values, validate it, apply it.
  • Comment Visibility Helper for Jira Service Management
    Always know whether the comment you are writing goes to the customer.
  • Queue Router for Jira Service Management
    Send each new request into the right queue by setting the fields queues filter on.
  • SLA Pause Report for Jira Service Management
    Which SLAs pause, which breach, and where.
  • Request Type Clone for Jira Service Management
    Clone a request type to another service desk and see exactly what is left to set up.
  • Attachment Gallery for Jira
    See an issue's images as a gallery, not a file list.
  • Bulk Transition for Jira
    Move many issues to another status, with every blocked issue explained first.
  • Sprint Scope Change Report for Jira
    How much a sprint's scope changed after it started, per sprint and per assignee.
  • Epic Progress Field for Jira
    A number field that says how far an epic got, and nothing else.
  • Assignee Load Gadget for Jira
    Who is carrying too much, as one bar per person.
  • Field Usage Map for Jira
    Every Jira field, the screens and schemes that use it, and the projects behind them.
  • Page Tree Exporter for Confluence
    Turn a page tree into Markdown files, attached where the tree starts.
