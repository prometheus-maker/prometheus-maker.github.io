Meeting Notes Kit

Meeting notes in Confluence, action items in Jira.

Create a structured meeting note in one click, then turn its action-item checkboxes into Jira issues from a macro on the page.

What it does

A meeting ends with notes in one place and follow-ups in another. The note records who agreed to what, and the actual work goes into Jira only if someone remembers to retype every action item - usually not all of them.

Meeting Notes Kit sets up a notes space once and then works inside it. From a Confluence page you create a new note with a topic and a date: the page is titled "Meeting <date> - <topic>", carries a standard body with Attendees, Agenda, Notes, Decisions and Action items, and gets a label so the kit can find it again. An optional parent page keeps a year of notes in one tree.

On the note page, the Meeting Actions macro reads the page's Confluence task list. Each item shows its state: Open, Done, or Linked with the Jira key it produced. Creating issues takes every incomplete item and opens one issue per item - summary from the item text, a description linking back to the note page, and a label - skipping completed items and the example row the template ships with. Each issue key is stored against the page, so pressing the button again does not create duplicates.

A single run creates at most 20 issues, and a failure is counted without stopping the rest. Setup is read from app storage: the notes space, the optional parent page, the Jira project key and the issue type by name. The kit never edits your task list, so the checkboxes stay yours to tick.

Install

Where to install it: Confluence Cloud, from the Atlassian Marketplace.

Open Confluence settings → Apps → Find new apps, search for the app name and click Install. After that the macro is available in the macro browser when you edit a page.

What you can do with it

You find it under the macro browser while editing a Confluence page.

  • One-click meeting note with a standard five-section body
  • Notes titled by date and topic, labelled so they can be listed
  • A page listing the latest notes in the space, newest first
  • Meeting Actions macro reading the page's Confluence task list
  • One Jira issue per incomplete action item, with a back-link to the note
  • Issue keys stored per page, so repeat runs do not duplicate
  • At most 20 issues per run, with counts for created, skipped and failed

Your data

The app runs on Atlassian Forge inside your own site. Settings and any cached results are stored in Forge storage, which belongs to your site; nothing is copied to another service, and nothing is read beyond what the app needs to do its job. Removing the app removes what it stored. Details: privacy policy.
