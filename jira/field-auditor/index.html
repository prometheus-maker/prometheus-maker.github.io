Field Auditor for Jira

Find unused and empty custom fields, screens and schemes.

Count how many issues use each custom field, see which screens and schemes point at it, and export the whole audit as CSV. Read-only, so it is safe on production.

What it does

Every Jira site that has been running for a few years carries custom fields nobody remembers adding. Some hold no value, some sit on no screen at all, and finding out which is which usually means writing a script against the admin API.

Field Auditor builds that picture for you. It joins custom fields, screens, field configurations and field configuration schemes into one table, with an issue count per field, so an unused field shows up next to the screen that still expects it.

The app is read-only. Nothing is edited or deleted, which means it runs safely on a production site during working hours, and its verdict column tells you which fields look safe to retire.

Filters narrow the table to just the unused fields or just the fields that sit on no screen, so the cleanup list is one click away. The audit exports as CSV with field id, name, type, issue count, screens, configurations, schemes, projects and verdict, ready to attach to a cleanup ticket.

Large sites are read in pages and the results are cached in Forge storage, so a second visit does not re-read thousands of issues.

Install

Where to install it: Jira Cloud, from the Atlassian Marketplace.

Open Apps → Manage your apps in Jira, choose Find new apps, search for the app name and click Install.

What you can do with it

You find it under Jira settings → Apps → Field Auditor for Jira.

  • One table of every custom field with usage count, type, screens, configurations, schemes and projects
  • Verdict per field: unused, on no screen, or in use
  • Filters for unused fields and fields on no screen
  • Shows which field configuration schemes point at each field
  • Read-only: no edits, no deletes, safe on production
  • CSV export of the whole table, verdict included
  • Paged reads and caching for large sites

Your data

The app runs on Atlassian Forge inside your own site. Settings and any cached results are stored in Forge storage, which belongs to your site; nothing is copied to another service, and nothing is read beyond what the app needs to do its job. Removing the app removes what it stored. Details: privacy policy.
