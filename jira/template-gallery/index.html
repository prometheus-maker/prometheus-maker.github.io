Template Gallery for Jira

Project templates that create a full set of issues and sub-tasks in one click.

Let a project admin define issue templates, then let anyone on the project create the whole structure - fields and sub-tasks - from a gallery.

What it does

Most work in a project starts the same way: a story with the same fields, the same three sub-tasks, the same labels. Setting that up by hand every time is slow and easy to get wrong.

Template Gallery keeps those structures in the project. A Jira admin builds a template once: the fields for the parent issue and any sub-tasks it should create. Project members then open the gallery page in the project, pick a template, look at the preview and create everything in one action.

Templates are per project and stored by the app, so changing a template never touches a workflow or a screen configuration. Usage counts show which templates the team actually relies on, and uninstalling the app removes the templates it stored.

Install

Where to install it: Jira Cloud, from the Atlassian Marketplace.

Open Apps → Manage your apps in Jira, choose Find new apps, search for the app name and click Install.

What you can do with it

You find it under Jira settings → Apps → Template Gallery for Jira.

  • A template editor on a Jira admin page, with fields plus optional sub-tasks
  • A gallery page inside each project with a preview before anything is created
  • One click creates the parent issue and all of its sub-tasks
  • A usage count per template, so unused templates are easy to spot
  • Templates are stored per project and never change your workflows or screens
  • Uninstalling removes the app's stored templates

Your data

The app runs on Atlassian Forge inside your own site. Settings and any cached results are stored in Forge storage, which belongs to your site; nothing is copied to another service, and nothing is read beyond what the app needs to do its job. Removing the app removes what it stored. Details: privacy policy.
