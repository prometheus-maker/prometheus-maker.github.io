Copy Field on Transition for Jira

Copy one field's value into another whenever an issue moves through a transition.

A workflow post function that carries a value from field to field at transition time, with the rules managed per project on an admin page.

What it does

Teams often need the same information twice: the story points that should land in a custom estimate field, the assignee that should be copied to a reviewer, the date that belongs in both a start and an approval field. Doing that by hand is easy to forget.

Copy Field on Transition adds a post function to a transition. An admin pairs a source field with a target field per project and transition on the app's admin page; every pass through that transition copies the value. A rule for all projects can sit behind the project-specific ones, and when several rules match, all of them run.

The behaviour stays conservative: an empty source copies nothing, and with overwrite turned off an existing target value is left alone. If a write fails, the transition continues and the admin page records the last error - unless the "block the transition if the copy fails" option is on, in which case the transition stops instead of leaving a half-filled issue. Stored rules are removed on uninstall.

Install

Where to install it: Jira Cloud, from the Atlassian Marketplace.

Open Apps → Manage your apps in Jira, choose Find new apps, search for the app name and click Install.

What you can do with it

You find it under Jira settings → Apps → Copy Field on Transition for Jira.

  • A workflow post function plus an admin page for the rules
  • Rules per project and transition, with an all-projects fallback
  • Every matching rule runs, project rules before the all-projects rule
  • Empty source values copy nothing; overwrite can be switched off per rule
  • Optional blocking when a copy fails, otherwise the error is recorded and shown
  • Stored rules removed on uninstall

Your data

The app runs on Atlassian Forge inside your own site. Settings and any cached results are stored in Forge storage, which belongs to your site; nothing is copied to another service, and nothing is read beyond what the app needs to do its job. Removing the app removes what it stored. Details: privacy policy.
