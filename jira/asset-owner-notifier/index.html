Asset Owner Notifier

Tell the JSM Assets owner the moment a linked issue needs them.

Read the Assets objects on an issue and add each owner as a watcher with a comment that mentions them by name.

What it does

Assets have named owners, but the person responsible for a laptop or a licence usually hears about a request only when a colleague remembers to tell them. The link from the issue to the object is there; the notification never happens.

Asset Owner Notifier listens to two events in one project you choose: issue created, and issue moved into a status you pick. On the event it reads the object key or keys in the issue's asset field - up to 25 per issue - and looks up an owner for each. Owners come from a CSV map you paste into the admin page (object key, account id, name, label, up to 200 entries), and from JSM Assets by AQL when a key is not in the map and the app has been given access to your Assets workspace.

For each owner found, it adds the person as a watcher and posts a comment that mentions them by name, with the object key, its label, the issue, the status and the summary. The comment text is a template you can edit. If the watcher call is refused by permissions, the comment is still posted and the log records it - an owner who cannot watch still gets told.

Repeat notifications to the same person on the same issue are suppressed for six hours after a transition; issue creation always notifies. The admin page shows counts and the last 50 attempts with their result, so a missing owner is a row in a log rather than a mystery. Settings, the owner map, the sent records and the log are deleted on uninstall.

Install

Where to install it: Jira Cloud, from the Atlassian Marketplace.

Open Apps → Manage your apps in Jira, choose Find new apps, search for the app name and click Install.

What you can do with it

You find it under Jira settings → Apps → Asset Owner Notifier.

  • Notifies on issue creation or on entering a chosen status, in one chosen project
  • Owner from a pasted CSV map of up to 200 object keys, then from Assets AQL
  • Up to 25 object keys per issue
  • Adds the owner as a watcher and mentions them in a comment
  • Editable comment template with object, issue and status placeholders
  • Six-hour duplicate suppression per person per issue on transitions
  • Last 50 attempts logged with a result; all data removed on uninstall

Your data

The app runs on Atlassian Forge inside your own site. Settings and any cached results are stored in Forge storage, which belongs to your site; nothing is copied to another service, and nothing is read beyond what the app needs to do its job. Removing the app removes what it stored. Details: privacy policy.
