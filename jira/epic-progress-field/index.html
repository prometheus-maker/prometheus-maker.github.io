Epic Progress Field for Jira

A number field that says how far an epic got, and nothing else.

A 0 to 100 custom field computed from an epic's child issues - story points when every child has an estimate, else issue count - refreshed hourly.

What it does

Epic progress in Jira is a bar you have to look at, not a number you can filter or sort. Teams that want "epics almost done" in a saved filter or on a roadmap end up counting children by eye.

Epic Progress Field adds a number custom field, 0 to 100, computed from the epic's child issues: story-point progress when every child has an estimate, issue-count progress otherwise. A line next to the value says which basis was used and the fraction behind it. Because it is a real number field, JQL works as usual: cf[<fieldId>] < 100 finds unfinished epics, = 100 finished ones, and "Epic progress" is EMPTY finds epics with no children.

An hourly job recomputes fifteen epics per run, and a Refresh button on the field updates one epic immediately. The value is written only when it changed, so the issue history stays clean. Uninstalling removes the queue and run state.

Install

Where to install it: Jira Cloud, from the Atlassian Marketplace.

Open Apps → Manage your apps in Jira, choose Find new apps, search for the app name and click Install.

What you can do with it

You find it under the custom field (add it to a screen in Jira settings → Issues → Screens).

  • A number custom field, 0 to 100, per epic
  • Story-point progress when all children are estimated, otherwise issue count
  • A value line naming the basis and the fraction
  • Plain JQL on the field: under 100, exactly 100, is empty
  • Hourly job recomputing 15 epics, plus per-epic Refresh
  • Writes only when the value changes; state removed on uninstall

Your data

The app runs on Atlassian Forge inside your own site. Settings and any cached results are stored in Forge storage, which belongs to your site; nothing is copied to another service, and nothing is read beyond what the app needs to do its job. Removing the app removes what it stored. Details: privacy policy.
