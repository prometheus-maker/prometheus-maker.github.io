Table of Contents+ Macro

Numbered, depth-limited table of contents for any Confluence page.

Add a numbered table of contents with anchor links, depth control and a back-to-top link to a page or a runbook tree.

What it does

A long policy page or runbook needs a table of contents that tells a reader where they are and how deep the page goes. The built-in list shows every heading at once, unnumbered, and a tree of pages gets a separate list on each page.

Insert Table of Contents+ on a page, then set it in the macro panel: a depth from one to six, numbering on or off, and whether to list this page only or this page and its children. Headings become numbered entries - 1, 1.1, 1.1.1 - and each entry links straight to its heading anchor, with an optional Back to top link at the end.

With "This page and children" chosen, the macro builds one list across the page tree, showing the page title above each group of headings. It reads at most 100 descendant pages and shows a note when a tree is larger.

Each result is cached for ten minutes and keyed by the page version, depth, numbering and scope, so a common view does not re-read Confluence on every load. The macro reads page bodies and writes nothing; its cache is removed on uninstall.

Install

Where to install it: Confluence Cloud, from the Atlassian Marketplace.

Open Confluence settings → Apps → Find new apps, search for the app name and click Install. After that the macro is available in the macro browser when you edit a page.

What you can do with it

You find it under the macro browser while editing a Confluence page.

  • Depth from 1 to 6, with 3 as the default
  • Numbered headings (1, 1.1, 1.1.1) that can be switched off, each linked to its anchor
  • This page only, or the page plus up to 100 descendant pages
  • Page titles shown above each group in a tree
  • Optional Back to top link
  • Ten-minute cache keyed by page version; cache removed on uninstall
  • Read-only: no page is edited

Your data

The app runs on Atlassian Forge inside your own site. Settings and any cached results are stored in Forge storage, which belongs to your site; nothing is copied to another service, and nothing is read beyond what the app needs to do its job. Removing the app removes what it stored. Details: privacy policy.
