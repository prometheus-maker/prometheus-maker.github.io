Issue Count Badge

A live Jira issue count on any Confluence page.

A Confluence macro that runs a JQL query and shows the matching issue count, with a warning colour above a threshold you set.

What it does

A Confluence page that reports on delivery usually carries a number that was true on the day it was written. "18 open bugs" is stale by the next stand-up, and nobody edits the page to fix it.

Issue Count Badge is a Confluence macro. You give it a JQL query, a title and optionally a warning threshold. It shows the number of matching issues as a badge, links to those issues in Jira's issue navigator, and tells you how old the number is. When the count reaches the threshold you set, the badge changes colour, which turns a status page into something you can read at a glance. A page can carry several badges, each with its own query and threshold.

Counts respect the viewer's permissions, because the query runs as the person reading the page rather than as the app - a page cannot be used to reveal issues someone is not allowed to see.

Results are cached per reader and per query for between 1 and 60 minutes, five by default, so a dashboard of badges does not run a query on every page view. A refresh control forces a new count. JQL is capped at 1000 characters, and invalid queries show Jira's own error message in place of a number.

Cached counts are stored by the app and removed on uninstall. The macro is read-only: it runs a search and draws the result.

Install

Where to install it: Confluence Cloud, from the Atlassian Marketplace.

Open Confluence settings → Apps → Find new apps, search for the app name and click Install. After that the macro is available in the macro browser when you edit a page.

What you can do with it

You find it under the macro browser while editing a Confluence page.

  • Any JQL query of up to 1000 characters
  • A badge with a title, linked to the matching issues in Jira
  • A warning threshold from 0 to 10000, with a colour change at or above it
  • Cache from 1 to 60 minutes, five by default, per reader and query
  • Counts run as the viewer, so page readers see only issues they may see
  • Jira's own query errors shown in place of a number
  • Cached counts removed on uninstall

Your data

The app runs on Atlassian Forge inside your own site. Settings and any cached results are stored in Forge storage, which belongs to your site; nothing is copied to another service, and nothing is read beyond what the app needs to do its job. Removing the app removes what it stored. Details: privacy policy.
