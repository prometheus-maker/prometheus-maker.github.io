Filter Usage Report

See which saved Jira filters are used, and which are dead weight.

One table of saved filters with the boards and dashboards that use them, least used first, plus a CSV export and a coverage line.

What it does

Saved filters accumulate for years. Nothing in Jira tells you which ones still carry a board or a dashboard, so clean-ups are guesswork and a filter someone relies on every morning can be deleted with the rest.

Filter Usage Report scans the site's saved filters, board configurations and shared dashboards and counts the uses of each filter: how many boards, how many dashboards, and the total. The table puts the least used filters first, which is where the dead weight is, and the whole table copies out as CSV for a clean-up meeting.

The scan is resumable: each batch reads up to 15 board configurations and 3 dashboards, and the page continues until it finishes, so a large site does not have to complete in one request. Only shared dashboards are read. A coverage line reports what the scan read, including how many dashboards it could not read, so an empty count is not mistaken for an unused filter.

Two limits are stated in the app: filters beyond the first 1,500 are counted as a lower bound and show a 0+-style total, and filter subscribers cannot be read from Jira, so they are not part of the count.

The report is read-only and requires the Administer Jira permission. Stored scan data is removed on uninstall.

Install

Where to install it: Jira Cloud, from the Atlassian Marketplace.

Open Apps → Manage your apps in Jira, choose Find new apps, search for the app name and click Install.

What you can do with it

You find it under Jira settings → Apps → Filter Usage Report.

  • Counts boards, dashboards and total uses per saved filter
  • Least used filters first
  • Resumable scan: 15 board configurations and 3 dashboards per batch
  • Coverage line with the counts read and the unreadable dashboards
  • Up to 1,500 filters counted, with capped totals marked
  • CSV of the whole table
  • Read-only; administrator permission required; data removed on uninstall

Your data

The app runs on Atlassian Forge inside your own site. Settings and any cached results are stored in Forge storage, which belongs to your site; nothing is copied to another service, and nothing is read beyond what the app needs to do its job. Removing the app removes what it stored. Details: privacy policy.
