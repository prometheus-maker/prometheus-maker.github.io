Label Tree for Confluence

Slash-separated labels become a browsable tree of your space.

A macro that groups pages by hierarchical labels like team/platform/api into a tree with counts, and marks the branch the current page belongs to.

What it does

Confluence labels are flat, so a space that uses them to build structure ends up with hundreds of them: team, team/platform, team/platform/api, and no way to walk that hierarchy without knowing the exact label to search.

Label Tree for Confluence reads the space around the page it sits on and turns slash-separated labels into a tree. A label "team/platform/api" creates three levels, and each level shows how many pages carry it - directly or through deeper labels - so a parent's number covers its whole subtree. Siblings are sorted by count, which puts the busy areas at the top.

The current page's own deepest slash label decides which branch is marked, so a reader can see where they are in the structure without clicking. Three levels are shown by default with expand controls for deeper branches, plus a Show all option. Every node links to a Confluence search for that label, so the tree is a navigation tool and not a dead diagram.

Labels without a slash are ignored: the macro is for hierarchical labels and leaves flat ones alone. It reads up to 1000 pages per space, in pages of 100, and reports when a space is larger. The built tree is cached per space for 15 minutes, with a refresh control on the macro.

The macro needs no write access. It reads pages and labels and renders them.

Install

Where to install it: Confluence Cloud, from the Atlassian Marketplace.

Open Confluence settings → Apps → Find new apps, search for the app name and click Install. After that the macro is available in the macro browser when you edit a page.

What you can do with it

You find it under the macro browser while editing a Confluence page.

  • A tree built from slash-separated labels, any depth
  • Page counts per level, including the whole subtree
  • Siblings sorted by count, deepest branches expandable
  • The current page's branch marked automatically
  • Every node links to a search for that label in the space
  • Three levels shown by default, with Show all
  • Up to 1000 pages per space, cached for 15 minutes, refresh control

Your data

The app runs on Atlassian Forge inside your own site. Settings and any cached results are stored in Forge storage, which belongs to your site; nothing is copied to another service, and nothing is read beyond what the app needs to do its job. Removing the app removes what it stored. Details: privacy policy.
