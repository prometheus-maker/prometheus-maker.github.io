Watcher Manager for Jira

Add or remove watchers on many issues at once, with a preview first.

Pick issues by JQL, a project role or named people, preview exactly which accounts change on which issues, then apply in batches with a per-issue error list.

What it does

Jira manages watchers one issue at a time. Adding a new team member to a queue, or an incident lead to a set of open tickets, means opening every issue and clicking the same button forty times. Bulk edit does not touch watchers at all.

Watcher Manager does it from one page. You define the issues with a JQL query and the people three ways: a project role, a search of active users, or a list you pick by hand. Nothing changes until you preview: the page lists which accounts will be added or removed on which issues, so a wrong role or a typo in the JQL is caught before it reaches anyone's inbox.

Applying runs in batches of fifty with a progress line, skips issues where nothing changes, and lists every failure by issue key with the reason. At the end you get one sentence: how many watchers were added, removed, skipped, and how many errors, so a partial run is visible instead of silent.

The page asks Jira whether you hold the Administer permission for the site and stops if you do not. Every watcher change runs as you, with your permissions.

Install

Where to install it: Jira Cloud, from the Atlassian Marketplace.

Open Apps → Manage your apps in Jira, choose Find new apps, search for the app name and click Install.

What you can do with it

You find it under Jira settings → Apps → Watcher Manager for Jira.

  • Issues selected by JQL, up to 200 per job
  • Audience from a project role, a user search, or named accounts
  • Preview of every add and remove before anything is applied
  • Batches of 50 with progress, skipping issues where nothing changes
  • Per-issue error list with the reason for each failure
  • Checks the Administer permission before it starts

Your data

The app runs on Atlassian Forge inside your own site. Settings and any cached results are stored in Forge storage, which belongs to your site; nothing is copied to another service, and nothing is read beyond what the app needs to do its job. Removing the app removes what it stored. Details: privacy policy.
