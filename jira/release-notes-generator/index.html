Release Notes Generator

Turn a version's fixed issues into release notes, ready to paste.

Generate Markdown or HTML release notes from the issues fixed in a Jira version, grouped by type and linked back to Jira.

What it does

Release notes get written at the worst possible moment: five minutes before a deploy, from a version's issue list, by someone copying summaries into a document and hunting for keys.

Release Notes Generator takes a project and a version and builds the notes from the issues whose fix version matches. Issues are grouped by type in a fixed order - bugs first, then stories, improvements, tasks and epics, with any other type last - each line a link back to the issue. You choose which issue types to include, add a header and a footer, and switch between Markdown and HTML of the same content.

The result appears in an editor, not as a finished document, so wording can be fixed before it is pasted anywhere. One draft is kept per project and version, up to 60,000 characters, so a notes document can be revised across a release instead of rebuilt.

The app reads the first 50 projects, 100 versions per project and up to 500 issues per generation, with a notice when a version is larger. It is read-only: no issue, version or release is changed. Drafts and the cached site address, which is kept for a day, are removed on uninstall.

Install

Where to install it: Jira Cloud, from the Atlassian Marketplace.

Open Apps → Manage your apps in Jira, choose Find new apps, search for the app name and click Install.

What you can do with it

You find it under the Apps menu in the top bar → Release Notes Generator.

  • Markdown or HTML from the same selection
  • Project and version pickers, with unreleased versions listed before released ones
  • Issues grouped by type, in a fixed order, each key linked back to Jira
  • Issue type checkboxes plus a header and footer you write
  • One editable draft per project and version, up to 60,000 characters
  • Pages through a version's issues, up to 500 per generation
  • Read-only; drafts removed on uninstall

Your data

The app runs on Atlassian Forge inside your own site. Settings and any cached results are stored in Forge storage, which belongs to your site; nothing is copied to another service, and nothing is read beyond what the app needs to do its job. Removing the app removes what it stored. Details: privacy policy.
