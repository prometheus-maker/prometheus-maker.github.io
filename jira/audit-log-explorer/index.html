Audit Log Explorer

Filter and export the Jira audit log by actor, action and date.

Search a date range of the Jira audit log with a text filter, narrow it by category, source and person, then export the changes as CSV.

What it does

Jira's audit log is written for machines: a long list of events that can be scrolled and text-searched, but not reshaped. When someone asks who changed a project's settings last month, or which permission changes touched a scheme, the answer means paging through events by hand and reading each one.

Audit Log Explorer is an admin page that reads the audit log for a date range and one text filter, then lets you narrow it further by category, event source and actor. Jira does the text matching; the app does the rest locally as it reads, so one search can be filtered several ways without querying Jira again.

Results show when each event happened, who did it, what the event was, the object it touched, and the before-and-after values when Jira recorded them. Rows page 25 at a time, and the whole result exports as CSV with one line per changed field - the shape a spreadsheet or a ticket wants, not the nested record Jira returns.

A search reads pages of 100 events, five pages per batch, and stops at 2000 events with a notice when the range is larger - narrow the dates rather than pushing past it. A running search can be cancelled. Reading the audit log needs the Administer Jira permission, and the page says so when it is missing.

The page only reads. Saved search criteria and the records it fetched are removed on uninstall.

Install

Where to install it: Jira Cloud, from the Atlassian Marketplace.

Open Apps → Manage your apps in Jira, choose Find new apps, search for the app name and click Install.

What you can do with it

You find it under Jira settings → Apps → Audit Log Explorer.

  • A date range plus Jira's own text filter
  • Local filters for category, event source and actor name
  • Rows showing the object, and the before and after values of a change
  • Paged results, 25 per page, with a running count and total
  • CSV export with one line per changed field
  • Up to 2000 events per search, read five pages of 100 at a time
  • Cancel a running search; nothing is modified

Your data

The app runs on Atlassian Forge inside your own site. Settings and any cached results are stored in Forge storage, which belongs to your site; nothing is copied to another service, and nothing is read beyond what the app needs to do its job. Removing the app removes what it stored. Details: privacy policy.
