CSV Field Bulk Set for Jira

Paste a CSV of issue keys and field values, validate it, apply it.

A Jira admin page that takes key,field,value rows, shows per-row errors in a dry run, then applies the valid rows in resumable batches.

What it does

When the source of truth for a field lives outside Jira - a spreadsheet from finance, a support export, a migration list - updating hundreds of issues by hand is where mistakes happen.

CSV Field Bulk Set takes pasted CSV with one row per line: issue key, field name (or customfield_ id), and value. Every row is validated against the target field's type - text, number, date, or a single option - and the dry run lists exactly what will be written and which rows cannot be: unknown fields, wrong types, missing issues.

Applying then writes only the valid rows, in batches of 20, with progress stored so a stopped run resumes instead of starting over. Up to 1000 rows fit in one file, values may be wrapped in double quotes, and field names are matched case-insensitively. The job list and its rows are removed from storage when uninstalled.

Install

Where to install it: Jira Cloud, from the Atlassian Marketplace.

Open Apps → Manage your apps in Jira, choose Find new apps, search for the app name and click Install.

What you can do with it

You find it under Jira settings → Apps → CSV Field Bulk Set for Jira.

  • Paste CSV directly: key, field, value, with an optional header
  • Field matched by name or customfield_ id, case-insensitive
  • Dry run shows every row's result and the per-row error when there is one
  • Supported types: text, number, date and single option
  • Resumable batches of 20 issues, up to 1000 rows per file
  • Quoted values supported; job history removed on uninstall

Your data

The app runs on Atlassian Forge inside your own site. Settings and any cached results are stored in Forge storage, which belongs to your site; nothing is copied to another service, and nothing is read beyond what the app needs to do its job. Removing the app removes what it stored. Details: privacy policy.
