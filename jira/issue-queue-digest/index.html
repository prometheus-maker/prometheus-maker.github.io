Queue Digest for Jira

One daily comment showing the work nobody has picked up.

A daily comment on a tracking issue with unassigned, untriaged and stale counts, each linked to a Jira search.

What it does

The issues that hurt a project are the ones nobody is assigned to, the ones that arrived with no priority, and the ones that have not moved in a fortnight. Each is a filter away, so nobody runs the filters.

Queue Digest posts them together. Once a day, at an hour and in a time zone you choose, it comments on a tracking issue in your project with three lines: unassigned issues that are not done, untriaged issues created within a window you set (seven days by default) that are still To Do with no priority, and stale issues not updated in a window you set (14 days by default). Each count links to the matching Jira search, and under each count come the oldest issues - up to 10 by default, configurable from 0 to 50 - with their age and priority.

The project lead is mentioned in the comment when you leave that on, so Jira's own notification reaches them. The project page previews the digest with the same numbers, shows when the next one goes out, and has Send now, with a Force send when today's digest already went and you need it again. Only one digest goes out per project per day.

Settings are per project and require the Administer Projects permission; the tracking issue must belong to the same project, which is checked on save. Digests are sent by the app's hourly trigger, so a quiet hour means nothing is sent. Project settings and the last-sent record are removed on uninstall.

Install

Where to install it: Jira Cloud, from the Atlassian Marketplace.

Open Apps → Manage your apps in Jira, choose Find new apps, search for the app name and click Install.

What you can do with it

  • Daily digest at an hour you pick, in any IANA time zone
  • Three buckets: unassigned, untriaged, stale
  • Each count linked to the Jira search behind it
  • Oldest issues listed per bucket, 0 to 50 rows, with age and priority
  • Optional mention of the project lead in the comment
  • Preview, Send now, and Force send on the project page
  • One digest per project per day; settings removed on uninstall

Your data

The app runs on Atlassian Forge inside your own site. Settings and any cached results are stored in Forge storage, which belongs to your site; nothing is copied to another service, and nothing is read beyond what the app needs to do its job. Removing the app removes what it stored. Details: privacy policy.
