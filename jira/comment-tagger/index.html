Comment Tagger for Jira

Mention a whole team in a Jira comment with one click.

Save named lists of users as aliases, then mention everyone correctly in one comment without retyping names.

What it does

Retyping the same four or six @mentions on every issue invites typos and leaves people out. The platform on-call list changes and the comment template does not, so the person who needed to know reads about it a day later.

Comment Tagger puts aliases in an admin page: a name such as platform-on-call or release approvers, filled from the user search, up to 200 members each and 100 aliases per site. Alias names are 1 to 40 characters, and members are picked from Jira's user search by name or email. On an issue, the panel has a comment box and one button per alias. Write the comment, click the aliases it concerns, and the panel states exactly who will be mentioned; posting creates one comment with a real mention for each member.

Mentions only notify people who can browse the issue, and the panel shows no user data beyond the names already in an alias. Aliases and settings live in storage; uninstalling removes them. An alias can be edited at any time, and the change applies to the next comment posted, not to comments already on issues.

Install

Where to install it: Jira Cloud, from the Atlassian Marketplace.

Open Apps → Manage your apps in Jira, choose Find new apps, search for the app name and click Install.

What you can do with it

You find it under the panel on the right side of any Jira issue.

  • Named alias lists built from the Jira user search
  • Up to 100 aliases per site and 200 members per alias
  • Comment box on the issue panel with one button per alias
  • A "Will mention" line naming everyone before you post
  • One posted comment with real mentions, not plain text names
  • Administrator page for creating and editing aliases
  • Stored aliases removed on uninstall

Your data

The app runs on Atlassian Forge inside your own site. Settings and any cached results are stored in Forge storage, which belongs to your site; nothing is copied to another service, and nothing is read beyond what the app needs to do its job. Removing the app removes what it stored. Details: privacy policy.
