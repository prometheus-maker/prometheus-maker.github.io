Label Manager for Jira

Count, rename, merge and delete Jira labels in bulk, with a dry run first.

See every Jira label with the number of issues using it, then rename, merge or delete it across the project. A dry run tells you exactly how many issues will change before anything is touched.

What it does

Jira labels are free text, so every project slowly collects billing, Billing, billing-old and a few temp-test tags nobody meant to keep. Nothing in Jira shows how many issues carry each label, and the built-in bulk editor is not built for four thousand issues at once.

Label Manager opens as a page under Jira settings. It lists every label with its issue count, and for each one you can rename it, merge it into another label, or delete it from the project. Every action starts with a dry run that states how many issues will be read and changed, so a mistyped merge is caught before it happens.

Big jobs do not need an open browser tab. The page queues the work and a scheduled job works through the issues in small batches, updating progress as it goes. When it finishes, the page lists every issue that failed, with the reason, so a partially successful rename is visible instead of silent.

Only a Jira administrator can open the app. It uses Jira's own permission checks for reading and editing issues, and the label data itself stays in Jira.

Install

Where to install it: Jira Cloud, from the Atlassian Marketplace.

Open Apps → Manage your apps in Jira, choose Find new apps, search for the app name and click Install.

What you can do with it

You find it under Jira settings → Apps → Label Manager for Jira.

  • Every label in a project with its exact issue count
  • Rename, merge or delete a label across the whole project
  • Dry run before each change, showing how many issues are affected
  • Long jobs run in batches on a scheduled trigger, so a 5,000-issue rename finishes without the page open
  • A list of issues that failed, with the reason, after each job
  • Clean-up on uninstall: queued job state is removed

Your data

The app runs on Atlassian Forge inside your own site. Settings and any cached results are stored in Forge storage, which belongs to your site; nothing is copied to another service, and nothing is read beyond what the app needs to do its job. Removing the app removes what it stored. Details: privacy policy.
