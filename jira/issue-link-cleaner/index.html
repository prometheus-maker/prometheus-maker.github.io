Issue Link Cleaner

Find and remove links to archived or missing issues.

Scan up to five projects for issue links whose target is missing or archived, review them by state, then remove them in a confirmed batch.

What it does

Issue links outlive the issues they point at. A project is archived after a migration, issues are deleted, and the links stay on the surviving issues - visible in the link panel, useless when clicked, and the reason a link matrix looks broken. Jira has no report for this and no bulk way to clean it up.

Issue Link Cleaner is an admin page in two phases. The scan reads the issues of up to five projects, optionally only one link type, and checks each link's target: whether it is still active, in a project that has been archived, missing altogether, or not readable by the app. Findings are counted by those four states and listed with source issue, target and state, filterable and paged.

Only two states are removable: targets that are missing and targets in an archived project. Links the app simply cannot read are left alone, so a permission problem is not mistaken for a dead link.

Removal is a separate step that you start after seeing the dry run, and it is permanent - Jira has no undo for a deleted link. Links are deleted 50 per batch, continuing on a five-minute schedule, with a removed count and a failure list; a job can be cancelled while it runs.

A scan reads at most 5000 issues and marks the result when it stopped there, and it resolves at most 60 unknown target issues per step, so a very tangled project takes several passes. The scan, removal and report records are removed on uninstall.

Install

Where to install it: Jira Cloud, from the Atlassian Marketplace.

Open Apps → Manage your apps in Jira, choose Find new apps, search for the app name and click Install.

What you can do with it

You find it under Jira settings → Apps → Issue Link Cleaner.

  • Scan up to five projects, all link types or one named type
  • Every link target classified as active, archived, missing or no access
  • Findings filterable by state, with source issue and target key
  • Removable states limited to missing and archived targets
  • Dry run first, then a separately started removal
  • Removed 50 links per batch, with failures listed and a cancel control
  • Up to 5000 issues per scan, marked when capped

Your data

The app runs on Atlassian Forge inside your own site. Settings and any cached results are stored in Forge storage, which belongs to your site; nothing is copied to another service, and nothing is read beyond what the app needs to do its job. Removing the app removes what it stored. Details: privacy policy.
