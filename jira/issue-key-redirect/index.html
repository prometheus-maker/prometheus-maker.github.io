Moved Issue Lookup

Resolve old Jira issue keys to where they live now.

Paste old issue keys and get the new key, project and status for each one, with a mapping CSV to share.

What it does

Old links in emails and documents break when a project key changes or an issue moves. The reader sees "issue does not exist" and has no way to find where the discussion went.

Moved Issue Lookup takes a list of old keys, one per line, or a CSV column pasted into the same box. For each key it reports what happened: moved, still here, not found, not visible, invalid key or an error. For a moved issue it shows the new key, the project and the current status, and the whole mapping copies out as CSV so the sender can fix the original links or share the map with a team.

Lookups run 25 keys per batch with progress, and a paste is capped at 500 keys, stated on the page. Each key is checked against the issue key format first, so a typo comes back as an invalid key without a request. The last result is restored when you come back, and an interrupted run resumes where it stopped.

A Forge app cannot redirect an old Jira URL. This page resolves keys on request; it does not sit in front of Jira and forward visitors. It only reads issues, and its stored keys and results are removed on uninstall.

Install

Where to install it: Jira Cloud, from the Atlassian Marketplace.

Open Apps → Manage your apps in Jira, choose Find new apps, search for the app name and click Install.

What you can do with it

You find it under the Apps menu in the top bar → Moved Issue Lookup.

  • Paste a list of keys or a CSV column
  • Six results: moved, still here, not found, not visible, invalid key, error
  • New key, project and status for each moved issue
  • Batches of 25 lookups with progress, up to 500 keys per paste
  • CSV mapping of old key to new key
  • Last result restored; interrupted run resumes
  • Read-only; stored data removed on uninstall

Your data

The app runs on Atlassian Forge inside your own site. Settings and any cached results are stored in Forge storage, which belongs to your site; nothing is copied to another service, and nothing is read beyond what the app needs to do its job. Removing the app removes what it stored. Details: privacy policy.
