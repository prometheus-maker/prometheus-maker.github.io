Duplicate Issue Detector for Jira

Point a new issue at the one it probably duplicates, before anyone works twice.

Scores each new issue's summary against the project's last six months and posts one internal comment naming the likely original.

What it does

Duplicates get created because nobody can search what they do not know exists. By the time someone notices, two people have done the same work.

Duplicate Issue Detector reads each newly created issue, compares its summary with issues from the last 180 days in the same project using token overlap, and - when the score passes a threshold - posts a single internal comment naming the closest match and its score. The comment is internal, so customers never see it.

The app is off until a Jira admin enables it per project, and the threshold is adjustable from 0.50 to 0.95 with 0.70 as the default. The admin page has a test box where a summary can be scored against the project before turning it on for real. Nothing else is changed: no links, no issues closed, no labels.

Install

Where to install it: Jira Cloud, from the Atlassian Marketplace.

Open Apps → Manage your apps in Jira, choose Find new apps, search for the app name and click Install.

What you can do with it

You find it under Jira settings → Apps → Duplicate Issue Detector for Jira.

  • Scores new issue summaries against six months of project issues
  • Posts one internal comment naming the likely original and the score
  • Off by default; enabled per project by a Jira admin
  • Adjustable threshold from 0.50 to 0.95 (default 0.70)
  • A test box to score a summary before enabling the rule
  • Never retries a failed check; errors are logged and left alone

Your data

The app runs on Atlassian Forge inside your own site. Settings and any cached results are stored in Forge storage, which belongs to your site; nothing is copied to another service, and nothing is read beyond what the app needs to do its job. Removing the app removes what it stored. Details: privacy policy.
