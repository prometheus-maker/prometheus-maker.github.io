Page Tree Exporter for Confluence

Turn a page tree into Markdown files, attached where the tree starts.

Pick a root page, preview its subtree, and export it as one Markdown file or a ZIP of one file per page, attached to the root.

What it does

Confluence holds years of decisions, and there is no export that respects the shape of a page tree. Exporting space by space produces HTML or PDF floods, and copying pages by hand loses the order.

Page Tree Exporter starts from any page you can read. It shows the subtree first - how many pages, which children - so you know what you are about to export. Then it converts each page's content to Markdown and either joins them into one file with headings for the hierarchy, or builds a ZIP with one file per page. The result is attached to the root page and linked on the app's page.

The export runs in batches (four tree requests or twenty-five page bodies per step) and shows progress, so a large tree does not time out. Trees are capped at 500 pages with a notice when one is larger. The app reads content and writes the attachment; nothing else on your pages is changed, and its stored job data is removed on uninstall.

Install

Where to install it: Confluence Cloud, from the Atlassian Marketplace.

Open Confluence settings → Apps → Find new apps, search for the app name and click Install. After that the macro is available in the macro browser when you edit a page.

What you can do with it

You find it under the Apps menu in the top bar → Page Tree Exporter for Confluence.

  • Any readable page as the root, with a subtree preview first
  • One Markdown file with headings for the hierarchy, or a ZIP of one file per page
  • The result is attached to the root page and linked
  • Batched export with a progress indicator
  • Trees over 500 pages are capped with a notice
  • Stored job data removed on uninstall

Your data

The app runs on Atlassian Forge inside your own site. Settings and any cached results are stored in Forge storage, which belongs to your site; nothing is copied to another service, and nothing is read beyond what the app needs to do its job. Removing the app removes what it stored. Details: privacy policy.
