Label Suggester for Jira

Suggest site labels as you type, so issues reuse them, not near-duplicates.

Add labels from an issue panel with live suggestions from your whole site, and a warning when a new label only differs from an existing one by case or punctuation.

What it does

Jira label lists drift into near-duplicates: customer, Customer and customer-1 all exist, and reports that filter on one miss the rest. The issue panel's label field offers no suggestions, so each person types from memory.

Label Suggester reads the site's existing label names, caches them for ten minutes, and as you type offers up to eight matches by prefix, substring and small spelling distance. If the label you typed differs from an existing one only by case or punctuation, it says so before you add it, with the existing name one click away.

Labels are saved by sending the issue's full label array, so nothing else on the issue changes. The panel is read-only for users without the Edit issues permission, and the cached label list is removed when the app is uninstalled.

Install

Where to install it: Jira Cloud, from the Atlassian Marketplace.

Open Apps → Manage your apps in Jira, choose Find new apps, search for the app name and click Install.

What you can do with it

You find it under the panel on the right side of any Jira issue.

  • Live suggestions from the site's existing labels while you type
  • Near-duplicate warning for case and punctuation variants
  • Add and remove labels from the issue panel
  • Read-only panel for users without Edit issues permission
  • Label list cached for ten minutes, capped at 5000 names
  • Cache removed on uninstall

Your data

The app runs on Atlassian Forge inside your own site. Settings and any cached results are stored in Forge storage, which belongs to your site; nothing is copied to another service, and nothing is read beyond what the app needs to do its job. Removing the app removes what it stored. Details: privacy policy.
