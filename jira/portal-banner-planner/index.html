Portal Banner Planner

Plan, time and copy your JSM portal announcement.

Schedule portal announcement campaigns, see which one is live, copy the exact text, and mirror it onto a Confluence page.

What it does

The JSM portal has a single announcement field and no calendar behind it, so notices go up late, stay up after the maintenance window, and nobody remembers which text was used.

Portal Banner Planner keeps a list of campaigns instead. Each campaign has text of up to 280 characters, an optional https link, and a start and end time in UTC. From those times every campaign is scheduled, live or ended, and the page shows the live one and the next one as cards above the table, so the notice that should be up now is never a guess. A Copy button produces the exact text to paste, with the link appended as "More: ..." when one is set.

Pasting into Project settings > Portals > Announcement is still yours to do: Atlassian has no API for that field, and the app does not pretend otherwise. What it adds is timing and memory - an hourly trigger records when each campaign went live and when it ended.

The same campaign can be appended to a Confluence page in one click. The app adds a dated paragraph to the existing storage-format body and increments the page version; if someone else edits the page at the same moment it reports the conflict instead of overwriting, and appending the same campaign to the same page twice is refused. Campaigns, the live state and the knowledge-base log live in Forge storage and are removed on uninstall. The page requires the Administer Jira permission.

Install

Where to install it: Jira Cloud, from the Atlassian Marketplace.

Open Apps → Manage your apps in Jira, choose Find new apps, search for the app name and click Install.

What you can do with it

You find it under Jira settings → Apps → Portal Banner Planner.

  • Campaigns with text up to 280 characters, an https link, and UTC start and end times
  • Live and next campaign shown as cards above the table
  • Scheduled, live and ended computed from the times and recomputed hourly
  • Copy button producing the exact portal text with the link appended
  • One-click append to a Confluence page, with version bump and conflict detection
  • Duplicate append of the same campaign to the same page refused
  • Admin-only page; all stored campaigns and the log removed on uninstall

Your data

The app runs on Atlassian Forge inside your own site. Settings and any cached results are stored in Forge storage, which belongs to your site; nothing is copied to another service, and nothing is read beyond what the app needs to do its job. Removing the app removes what it stored. Details: privacy policy.
