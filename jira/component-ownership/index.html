Component Ownership Map

Give every component an owner and suggest them on each issue.

Assign an owner and backup per Jira component, show the owner on the issue, and optionally auto-assign new issues to them.

What it does

Components are the closest thing most Jira projects have to a team structure - the API, the billing screen, the mobile app - but Jira does not connect a component to a person. New issues land unassigned, or with whoever triages, and the decision about who really owns that area lives in someone's head.

Component Ownership Map is a project settings page. It reads the project's components and lets a project admin set an owner and an optional backup on each one. The map shows the open issue count next to every component, so ownership is set against real load - the first 40 components are counted, and the page says when a project has more.

On an issue, a panel reads that issue's components and names the owner. When the issue's components belong to one person, the panel offers Assign to them in one click; when components point at different people, it says so and lists both rather than guessing.

Auto-assign is off by default and switched on per project. When it is on, a newly created issue that has no assignee and components with exactly one owner is assigned to that owner, and the last ten auto-assignments are listed on the settings page so the rule stays visible.

Owners are stored by the app, not written to Jira's component records, and every stored owner map is removed on uninstall. The panel needs no write access unless someone presses Assign.

Install

Where to install it: Jira Cloud, from the Atlassian Marketplace.

Open Apps → Manage your apps in Jira, choose Find new apps, search for the app name and click Install.

What you can do with it

You find it under the panel on the right side of any Jira issue.

  • Owner and optional backup per component, set in project settings
  • Open issue count beside each component, for the first 40
  • An issue panel naming the component owner
  • One-click Assign to the owner when components agree
  • Conflict shown, not guessed, when components have different owners
  • Optional auto-assign of new unassigned issues, with the last ten actions listed
  • Stored maps removed on uninstall

Your data

The app runs on Atlassian Forge inside your own site. Settings and any cached results are stored in Forge storage, which belongs to your site; nothing is copied to another service, and nothing is read beyond what the app needs to do its job. Removing the app removes what it stored. Details: privacy policy.
