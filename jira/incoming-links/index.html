Incoming Links for Confluence

See which pages link to this one, grouped by space.

Add a "Linked from" macro to any Confluence page: the pages that link to it, grouped by space, with direct links and a refresh button.

What it does

Confluence tells you where a page points. It does not tell you who points at it. That is exactly the question you ask before renaming, moving or archiving a page, because every link into it is a page that will break.

Incoming Links adds a macro you can drop on any page. It searches the site for pages that mention the page's title, reads their bodies, and keeps only the ones that really contain a link to this page. The result is grouped by space with the space name and each page's title, so you can see which teams depend on it rather than guessing from the space tree.

Results are cached for ten minutes so the macro stays fast on a page people visit often, and a refresh button forces an immediate recheck after you have edited links.

All matching happens inside Forge with the permissions of the person viewing the macro: pages they cannot read never appear, and page content is never sent anywhere outside your site.

Install

Where to install it: Confluence Cloud, from the Atlassian Marketplace.

Open Confluence settings → Apps → Find new apps, search for the app name and click Install. After that the macro is available in the macro browser when you edit a page.

What you can do with it

You find it under the macro browser while editing a Confluence page.

  • A macro for any page that lists the pages linking to it
  • Each candidate page's body is checked for a real link, so mentions alone are not counted
  • Grouped by space, sorted by space name and page title
  • Direct links to each referring page
  • Ten-minute cache, plus a refresh button for an immediate recheck
  • Respects the viewer's permissions: unreadable pages never appear

Your data

The app runs on Atlassian Forge inside your own site. Settings and any cached results are stored in Forge storage, which belongs to your site; nothing is copied to another service, and nothing is read beyond what the app needs to do its job. Removing the app removes what it stored. Details: privacy policy.
