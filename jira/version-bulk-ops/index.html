Version Bulk Ops for Jira

Release, archive, merge or delete project versions across all their issues at once.

Clean up a project's version list safely: preview the affected issues, confirm by typing, then remap fix and affects versions in batches.

What it does

Version lists accumulate: releases that never shipped, duplicates named slightly differently, versions used by five issues that nobody dares delete. Jira will not let a version go while issues still carry it, so the clean-up is either done issue by issue or not at all.

Version Bulk Ops lists the project's versions with their issue counts and plans the operation - release, archive, merge into another version, or delete. Before anything is written, the plan shows which issues will be touched. Applying needs a typed confirmation, then the app remaps Fix versions and Affects versions in batches of 20 issues and only at the end removes the old versions.

Plans are limited to 500 issues at a time, run with project admin permission, and progress is stored so a stopped run can be resumed. Everything the app stores is removed on uninstall.

Install

Where to install it: Jira Cloud, from the Atlassian Marketplace.

Open Apps → Manage your apps in Jira, choose Find new apps, search for the app name and click Install.

What you can do with it

You find it under Jira settings → Apps → Version Bulk Ops for Jira.

  • Version list with issue counts for a project
  • Release, archive, merge and delete, each with a preview plan
  • Typed confirmation before any change
  • Fix versions and Affects versions remapped in batches of 20
  • Up to 500 issues per plan, resumable if interrupted
  • Stored plans and job state deleted on uninstall

Your data

The app runs on Atlassian Forge inside your own site. Settings and any cached results are stored in Forge storage, which belongs to your site; nothing is copied to another service, and nothing is read beyond what the app needs to do its job. Removing the app removes what it stored. Details: privacy policy.
