Admin Daily Digest

The state of the Jira site, one comment a day.

One daily comment on a tracking issue: new projects and users, issues created, resolved and open, and the high-priority work getting old.

What it does

A Jira administrator is asked "has anything changed?" and answers by opening four admin pages and three filters. The things worth knowing arrive one at a time, usually after somebody notices them.

Admin Daily Digest posts one comment a day on a tracking issue you choose, mentioning the recipients you list. It reports new projects since the last digest, new users first seen since then, issues created and resolved in the last 24 hours, the current open count, and the high-priority issues that are not done and were created more than a set number of days ago. Every count links to the matching Jira search and every at-risk row links to its issue, with priority, age and assignee.

The numbers have limits. Jira accounts carry no creation date, so "new users" means first seen since the previous digest: the first digest after install reports none and records the baseline. User lists are read up to 2000 accounts, and the comment says "first 2000 accounts" when it hit that. At-risk rows are limited to the number you set, 1 to 50.

You choose the hour, the time zone, the at-risk age (1 to 90 days) and the recipients. The admin page previews the exact comment text, shows the last run, and has Send now and Force send. Only users with the Administer Jira permission can change settings or send. The app does not report automation rules or SLA values, which have no public API, and keeps no data beyond its snapshots, settings and last run - all deleted on uninstall.

Install

Where to install it: Jira Cloud, from the Atlassian Marketplace.

Open Apps → Manage your apps in Jira, choose Find new apps, search for the app name and click Install.

What you can do with it

You find it under Jira settings → Apps → Admin Daily Digest.

  • Daily comment on a tracking issue at an hour and time zone you set
  • New projects and new users since the last digest
  • Issues created and resolved in the last 24 hours, and the open count, each linked to a search
  • At-risk high-priority issues older than 1 to 90 days, up to 50 rows
  • Recipients mentioned by name in the comment
  • Preview, Send now and Force send on the admin page
  • User list read up to 2000 accounts, with the cap stated; data removed on uninstall

Your data

The app runs on Atlassian Forge inside your own site. Settings and any cached results are stored in Forge storage, which belongs to your site; nothing is copied to another service, and nothing is read beyond what the app needs to do its job. Removing the app removes what it stored. Details: privacy policy.
