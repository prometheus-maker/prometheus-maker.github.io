Queue Router for Jira Service Management

Send each new request into the right queue by setting the fields queues filter on.

Ordered rules match on request type, a portal field or priority and set the assignee and priority, on a five-minute schedule.

What it does

JSM queues are saved filters, but the API will not write to them. Routing a request therefore means setting the fields a queue filters on, usually with automation rules that grow into a maze.

Queue Router keeps that in one ordered list. Each rule matches on request type, a portal field value or priority, and sets the assignee and priority the queue needs. The first enabled rule that matches wins, and only fields that actually change are written, so the request's history stays readable.

An admin page holds the rules with a preview that shows which requests a rule would match and a dry run before applying. A scheduled run works through 25 requests per invocation and remembers its page token, so a large service desk is covered without long invocations. Rules and job state are removed when the app is uninstalled.

Install

Where to install it: Jira Cloud, from the Atlassian Marketplace.

Open Apps → Manage your apps in Jira, choose Find new apps, search for the app name and click Install.

What you can do with it

You find it under Jira settings → Apps → Queue Router for Jira Service Management.

  • Ordered rules matching on request type, a portal field value or priority
  • Sets assignee and priority, the fields JSM queues filter on
  • First enabled matching rule wins; only changed fields are written
  • Preview of matching requests and a dry run before applying
  • Five-minute scheduled run, 25 requests per invocation, resumable
  • Rules and job state removed on uninstall

Your data

The app runs on Atlassian Forge inside your own site. Settings and any cached results are stored in Forge storage, which belongs to your site; nothing is copied to another service, and nothing is read beyond what the app needs to do its job. Removing the app removes what it stored. Details: privacy policy.
